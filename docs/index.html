核心功能

功能按真实采集流程组织：先找作品，再看评论和详情，也可以直接整理某个主页的公开作品。

关键词

作品采集

按关键词搜索快手作品，整理标题、话题、作者、发布时间、播放和点赞等信息。

评论区

评论采集

采集指定作品或搜索结果作品下的评论数据，导出评论内容、用户和互动信息。

详情页

作品详情

根据作品链接采集播放、点赞、评论、收藏、分享、封面和视频直链等详情字段。

主页

主页作品

输入目标用户主页，批量整理公开作品列表，并可按需下载视频文件。

适合哪些使用场景

公开页面介绍尽量保持中性，重点放在数据整理、账号研究和内容运营，避免夸大承诺。

内容研究整理某个关键词下的作品表现、话题方向和发布时间。
账号运营查看同行或目标账号的公开作品列表和更新情况。
评论整理批量导出评论内容、评论时间、点赞数和用户信息。
素材归档保存公开作品的基础信息、视频直链或本地视频文件。
链接处理处理 App 分享链接、PC 链接、主页链接、快手号和 UID。
数据复盘将结果导出为 CSV，在 Excel、WPS 或数据工具里继续分析。

使用流程

客户端已经打包好运行环境，主要工作是下载、配置 Cookie、选择模块并等待结果导出。

下载客户端从 GitHub Releases 下载最新版 Windows 或 macOS 客户端。
配置 Cookie使用软件内置 Cookie 工具获取自己的快手账号登录态。
登录授权使用购买后获得的卡密登录软件，一机一码授权。
选择模块输入关键词、作品链接、主页链接、快手号或 UID，并选择是否下载视频。
查看结果采集完成后，在软件所在目录查看 CSV、视频文件和日志文件。

常见问题

这里回答购买前最常见的问题。更细的字段说明和报错反馈格式请看 README。

是否需要安装 Python？

不需要。软件已经打包为桌面客户端，下载对应系统版本后即可运行。

Cookie 需要手动抓包吗？

软件内置 Cookie 工具，用于辅助获取当前账号登录态，减少手动抓包操作。

结果保存在哪里？

默认保存在软件所在目录，CSV、视频文件和日志会按功能模块分别生成。

采集中断后数据会丢失吗？

软件会在采集过程中持续保存结果，已完成部分通常会保留在 CSV 文件中。

准备开始采集快手公开数据？

先看演示或下载最新版，也可以直接进入商品页开通授权。
