使用前请先确认

  • Windows 10/11 或 macOS下载对应安装包，解压后直接运行，不需要配置 Python。

常见问题

以下问题会直接影响采集结果，建议购买前阅读。

是否需要安装 Python？

不需要。软件已打包为 Windows 和 macOS 桌面客户端，下载对应版本后解压运行。

需要登录快手吗？

按当前版本提示配置登录态即可；采集的是公开可见的作品与评论。

能采多少条评论？

受作品可见范围、账号状态和平台规则影响，没有固定上限；建议分批采集并保留日志。

采集中断后数据会丢失吗？

软件按页保存 CSV，网络异常或中断通常不会清空已写入的内容。采集时不要打开结果文件。

视频下载失败怎么办？

检查作品链接是否有效、网络是否正常、输出目录是否可写；单条失败通常不影响后续任务。

支持哪些系统？

支持 Windows 10/11 和 macOS，下载对应安装包即可，无需安装 Python。
